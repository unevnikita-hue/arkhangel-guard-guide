# Памятка охранника

Небольшой автономный PHP-модуль: сотрудник указывает ФИО, прокручивает памятку,
подтверждает ознакомление, а сервер добавляет событие в закрытый JSON-журнал.

## Установка

1. Нужен PHP 8.1+ с расширениями `json`, `session` и `mbstring`.
2. Направьте web-root сайта на каталог `public/`.
3. Дайте пользователю PHP право создавать файлы в каталоге `storage/`
   (обычно владелец web-процесса и права `770` на каталог; `777` не нужен).
4. Откройте `/guard-guide/` либо корень выделенного виртуального хоста.

Текст памятки меняется в [`content/memo.php`](content/memo.php). После
существенного изменения текста обязательно измените `memo_version` в
[`config.php`](config.php).

Текущая редакция перенесена из [Google Docs](https://docs.google.com/document/d/1zNDajylwNok_4xk0CB7Ho4NJ1b5w9sJ8gZOiPEzBDwM/edit)
20.08.2026. Перед реальным кадровым пилотом текст, особенно раздел «Вахта не
рекомендована», требует содержательной и юридической проверки владельцем.

Журнал по умолчанию находится в `storage/acknowledgements.json`, то есть вне
публичного каталога `public/`. Его путь можно переопределить переменной окружения
`GUARD_GUIDE_STORAGE_PATH`.

Для локального запуска:

```bash
php -S 127.0.0.1:8080 -t public
```

Для проверки:

```bash
php tests/run.php
```

## Ограничения

Модуль фиксирует технический факт отправки формы пользователем, указавшим ФИО.
Модуль не использует электронную подпись и не обеспечивает криптографическую
идентификацию физического лица. Признак прокрутки устанавливается JavaScript и
может быть подделан технически подготовленным пользователем.
