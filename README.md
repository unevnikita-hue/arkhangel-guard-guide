# Памятка охранника

Каноническое место нового небольшого внутреннего модуля программного
обеспечения «Архангел».

Статус: Discovery — функциональные требования ещё не зафиксированы.

## Архитектурная граница

Production-модуль создаётся только внутри существующего ПО «Архангел».
Отдельный сервис, приложение или параллельная production-система запрещены.
API у «Архангела» отсутствует; внутренний способ подключения модуля пока
неизвестен и будет определён после обследования фактической архитектуры.
